## General instructions — before checking off any stage

A stage's checkboxes are a completion record, not a to-do list to leave partially ticked. Before
marking **any** action item `[x]` or writing a stage's "Completed" note:
- Every action item under that stage must actually be done — not "done in spirit" or "the risky
  part is done."
- Verification claimed in a checkbox (tests green, deployed, live-verified) must have actually
  been run this session, not assumed from a prior session's note.
- If a stage turns out to be partially blocked or partially out of scope, say so explicitly in the
  stage's own writeup rather than checking the box and moving on.
- Add a **Completed** note (date + what actually happened) and, where the stage hands anything to
  a later stage, a **Handoff** note — before considering the stage closed out in this document.
